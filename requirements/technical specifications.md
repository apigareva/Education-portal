# Техническое задание — Course registration

## 1. Постановка задачи
 
Education portal - внутренний портал обучения для сотрудников.
Необходимо реализовать возможность записи сотрудников на курсы на портале обучения. 

- добавить кнопку "записаться"
- записывать на курс, если места еще есть
- если при записи мест нет, то показывать ошибку
- нельзя записать одного сотрудника на курс дважды

## 3. Границы системы
 
- Предполагаем, что уже существует сервис уведомлений внутри компании, который можно использовать для уведомления об успешной или неуспешной записи.
- Для MVE считаем, что есть только роль сотрудника и роль администратора, роли руководителя с расширенным функционалом нет.

## 2. Роли и права

- кто может записать сотрудника (сам сотрудник, руководитель)
- кто может отменить запись (администратор, руководитель)
- кто может просматривать записи на курс (сотрудник, руководитель, администратор)

## 3. Функциональные требования

- отображение списка курсов
- возможность посмотреть детальное описание курса
- возможность поиска по курсам
- возможность нажать на кнопку записи 
- возможность отменить запись
- подтверждение записи
- просмотр уведомлений по курсам
- возможность посмотреть все свои записи на курс

## 4. Нефункциональные требования

- добавить ограничение на запись неуникальных значений в бд регистраций UNIQUE (course_id, user_id)

## 5. Интеграции

### Очередь

Отправляем в очередь запись на регистрацию на курс
Параметры сообщения
| Название параметра | Тип | Обязательность | Описание |
|------|------|------|------|
|course_id|string|yes| Уникальный идентификатор курса|
|user_id|string|yes| Уникальный идентификатор пользователя|
