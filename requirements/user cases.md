# Сценарии использования User Cases - Course registration

| | |
| :--- | :--- |
| **Заголовок** | Регистрация на курс |
| **Участники** | Пользователь |
| **Предусловие** | Пользователь находится на внутреннем портале обучения с курсами |
| **Триггер** | Нажимает на кнопку Записаться на курс |
| **Ожидаемый результат** | Пользователь записан на курс |
| **Основной сценарий** | 1. Пользователь выбирает курс<br> 2. Пользователь нажимает на кнопку Записаться<br> 3. Пользователь заполняет форму подтверждения записи<br> 4. Пользователь нажимает кнопку Подтвердить<br> 5. Пользователь получает уведомление об успешной записи или причину отказа записи на курс|
| **Альтернативные сценарии** | 1. Если пользователь пытается зарегистрироваться на курс, на котором нет мест, то получает сообщение об ошибке.<br> 2. Если пользователь не заполнил форму подтверждения и нажал отмена, то он не записывается на курс.<br> 3. Несколько пользователей одновременно регистрирутся на курс, когда остается одно последнее место, то запись на регистрацию создается для первого в очереди, остальным приходит уведомления о неуспешной попытке записи.<br> 4. Пользователь пытается записаться на курс повторно, получает уведомление о том, что повторная запись невозможна.|
