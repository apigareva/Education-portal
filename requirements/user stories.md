# User Stories - Course registration

## Общий контекст

Сервис регистраций предназначен для записи сотрудников на курсы на внутреннем портале обучения сотрудников.

## Роль: Администратор (Admin)

### Управление записями регистраций

- **US-ADMIN-01**: Может отменять (удалять) записи на регистрацию.
- **US-ADMIN-02**: Может просматривать все регистрации на курсы.
- **US-ADMIN-03**: Может фильтровать записи по курсам.
- **US-ADMIN-04**: Может фильтровать записи по пользователям.

## Роль: Пользователь (User)

### Дашборд курсов

- **US-USER-01**: Просматривать все курсы
- **US-USER-02**: Осуществлять поиск по курсам
- **US-USER-03**: Записываться на выбранный курс

### Карточка подтверждения записи

- **US-USER-04**: Заполнять данные формы для подтверждения записи

### Дашборд регистраций

- **US-USER-05**: Просматривать все свои регистрации на курсы
- **US-USER-06**: Осуществлять поиск по своим регистрациям
